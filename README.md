# Cybersecurity Incident Report: SYN Flood Attack

## Project Overview
I reviewed a cybersecurity incident involving a website that became inaccessible to legitimate employees. I analyzed the incident details to identify a possible **Denial-of-Service (DoS) SYN flood attack** and understand how it could disrupt the web server.

## Key Findings
- Investigated website connection timeouts.
- Examined reported suspicious traffic patterns.
- Explained how a SYN flood can overwhelm server resources.
- Documented the findings in a cybersecurity incident report.

## Skills Demonstrated
- Network security
- Incident analysis
- Log interpretation
- TCP/IP fundamentals
- Technical report writing

**Note:** The SYN flood attack is a suspected cause based on the available incident details and has not been independently confirmed.
